## Authority order

```text
1. 最新、明确且未被推翻的用户决定
2. docs/constitution/00–09
3. docs/status/Current-State.md
4. docs/architecture/00–08
5. docs/research/Current-Research-Program.md
6. docs/specs/**
7. docs/roadmap/Phase-D-Work-Packages.md
8. 当前代码、测试和可复现 Artifact（用于实现事实）
9. docs/archive/** 和标记 HISTORICAL/SUPERSEDED 的材料
```

规范性目标和实现事实必须分开：Constitution 决定“应该做什么”；代码、测试和运行 Artifact 决定“实际完成了什么”。
