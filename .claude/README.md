# Claude Code Project Assets

`CLAUDE.md` imports the shared `AGENTS.md` contract. Current architecture, status and Roadmap live only under the paths linked by `docs/README.md`.

Available read-only reviewers:

- `platform-kernel-reviewer`: identity, time, evidence, PostgreSQL and Governance boundaries;
- `research-evidence-reviewer`: PIT, leakage, qualification and research-claim ceilings;
- `repository-verifier`: diff, migration, tests and documentation verification.

Available procedures:

- `/implement-work-package`: execute one user-supplied bounded specification or one current Roadmap item;
- `/verify-repository`: run the current validation matrix;
- `/reconcile-branches`: only for an explicitly requested branch audit.

The former WP-PDL continuous-program skill was removed because its source documents were superseded and deleted from the default tree. Do not reconstruct that plan from Git history. Use `docs/status/Roadmap.md` and current code facts.

No project asset grants permission to alter Git history, inflate evidence, promote a model or perform broker mutation.
